# apb 0.17.0

This release adds the Qoder CLI as the ninth built-in coding agent and refreshes the curated models table against current vendor pricing, including the model families Qoder serves.

## Qoder CLI as a built-in agent

Profiles can now bind `agent: qoder` (qoder.com/cli). Qoder is detected on PATH like the other agents, runs headless in print mode with the prompt as a positional argument, and carries the SOUL through its native `--append-system-prompt` flag, so the role prompt rides alongside Qoder's own agentic system prompt instead of replacing it. Autonomous runs use `--permission-mode bypass_permissions`. The invocation declares the resume ceiling with a `--resume` form wired in, but with plain-text output pinned the session id is not captured today, so follow-up rounds re-prompt with fresh context, the same behavior cursor has. As an aggregator serving Qwen, DeepSeek, GLM, Kimi and MiniMax models under one subscription, Qoder follows the cursor pattern: no vendor lock, the full curated table is offered for model selection.

The agent appears automatically in `apb init` onboarding, the `agents_detect` MCP tool, the web dashboard agent picker and the profiles documentation.

## Curated models table refresh (2026-08-15)

All vendor rows were re-verified against official pricing pages. Price corrections: gpt-5.6-terra to 2.0/12.0 and gpt-5.6-luna to 0.2/1.2 per million tokens after vendor price cuts, o4-mini to 1.10/4.40 fixing a wrong value, and claude-sonnet-5's launch pricing is now recorded as the permanent list price.

New rows: claude-opus-5 (also added to the Claude CLI static model list), gemini-3.7-flash and gemini-3.5-flash-lite, grok-4.6, qwen3.8-max, and two new vendors serving the Qoder lineup, kimi-k3 (Moonshot) and glm-5.2 (Zhipu).

Dropped rows: grok-4, which no longer exists on the xAI models page, and llama-4-maverick, after Meta wound down its first-party Llama API and the pricing source went dead.

A note in the table flags DeepSeek's switch to peak and off-peak billing on 2026-08-16; those rows keep the still-current flat rates and need a follow-up refresh once the new scheme settles.
