# Advisor question packet

Give the advisor this packet and nothing else. A clean context means no
earlier conversation, no implementer reasoning and no other advisor's answer.

## Packet

1. **Task.** The original request in its own words, and the reference to it.
2. **Expected outcomes.** Observable, numbered.
3. **Exclusions and preserved behavior.**
4. **Facts.** What the code and docs say, with file references.
5. **Questions.** One decision each. For every question:
   - the real options;
   - what each option costs;
   - the sources behind it.
6. **Ask.** For each question: the choice, the reason, the risks, and a
   plausible wrong implementation that would pass the proposed acceptance.

## Reading the answer

- Check every factual claim against the source before you rely on it.
- Agreement on a choice is agreement only when the reasons hold.
- A disagreement gets one targeted follow-up with the conflicting facts.
- Record what the advisor actually said, not a summary that fits your view.
